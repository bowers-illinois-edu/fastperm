# fastperm: Fast, General Permutation Testing with Sensitivity Analysis

Fast permutation tests for arbitrary test statistics and
as-if-randomized designs, with optional Rosenbaum-style sensitivity
analysis over Gamma. See `docs/memo.md` for the design document.
Methodology not yet implemented.
