# Package index

## Saddlepoint p-values

Tail probabilities of a test statistic under the within-stratum
permutation null.

- [`fastperm_spa_linear()`](https://bowers-illinois-edu.github.io/fastperm/reference/fastperm_spa_linear.md)
  : Saddlepoint permutation p-value for a linear statistic
- [`fastperm_spa_quadratic()`](https://bowers-illinois-edu.github.io/fastperm/reference/fastperm_spa_quadratic.md)
  : Saddlepoint tail probability of a quadratic form under the
  permutation null
- [`saddlepoint_tail()`](https://bowers-illinois-edu.github.io/fastperm/reference/saddlepoint_tail.md)
  : Saddlepoint tail probability of a linear statistic

## Cumulant generating functions

Exact permutation CGFs of linear statistics, the input to the
saddlepoint.

- [`fastperm_linear_cgf()`](https://bowers-illinois-edu.github.io/fastperm/reference/fastperm_linear_cgf.md)
  : Exact CGF of a linear statistic under the within-stratum permutation
  null
- [`fastperm_linear_cgf_mv()`](https://bowers-illinois-edu.github.io/fastperm/reference/fastperm_linear_cgf_mv.md)
  : Joint CGF of a vector of linear statistics under within-stratum
  permutation
